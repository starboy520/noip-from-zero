# 第 5 章 组合条件与逻辑运算

## 5.1 一个条件有时不够

生活中的规则常常同时包含多个要求：

- 成绩至少 60 **并且** 出勤率至少 80；
- 年龄小于 6 **或者** 年龄至少 65；
- 答案 **不是** 0。

C++ 使用三个逻辑运算符组合条件：

| 写法 | 读法 | 含义 |
|---|---|---|
| `&&` | 并且 | 两边都成立，整体才成立 |
| `||` | 或者 | 两边至少一边成立，整体就成立 |
| `!` | 不、取反 | 把成立变成不成立，把不成立变成成立 |

## 5.2 `&&`：两个要求都要满足

```cpp
score >= 60 && attendance >= 80
```

只有两边都成立，整个条件才成立。

| `score >= 60` | `attendance >= 80` | 整体结果 |
|---|---|---|
| 成立 | 成立 | 成立 |
| 成立 | 不成立 | 不成立 |
| 不成立 | 成立 | 不成立 |
| 不成立 | 不成立 | 不成立 |

完整程序：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score, attendance;
    scanf("%d%d", &score, &attendance);

    if (score >= 60 && attendance >= 80) {
        printf("Qualified\n");
    } else {
        printf("Not qualified\n");
    }

    return 0;
}
```

## 5.3 `||`：至少满足一个要求

某活动规定：年龄不超过 6 岁或者至少 65 岁，可以获得优惠。

```cpp
age <= 6 || age >= 65
```

只要一边成立，整体就成立：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int age;
    scanf("%d", &age);

    if (age <= 6 || age >= 65) {
        printf("Discount\n");
    } else {
        printf("Regular\n");
    }

    return 0;
}
```

这里的“或者”允许两边都成立。不过在这个年龄例子中，一个年龄不可能同时不超过 6 又至少 65。

## 5.4 `!`：把结果反过来

```cpp
!(n == 0)
```

表示“`n == 0` 不成立”，也就是 `n` 不等于 0。它和下面的条件作用相同：

```cpp
n != 0
```

初学时，能直接写成 `!=` 就优先写 `!=`，通常更容易读。`!` 更适合对一个完整条件取反。

## 5.5 用括号让条件更清楚

如果条件较长，可以用圆括号标出组合关系：

```cpp
(score >= 60 && attendance >= 80) || special == 1
```

意思是：

```text
成绩和出勤都达标
或者
special 等于 1
```

本教程现阶段要求：混合使用 `&&` 和 `||` 时主动加括号，不依赖运算优先级猜测。

## 5.6 区间条件要拆成两次比较

数学中会写 `60 <= score < 90`，但 C++ 不能照抄这种连续写法。应写成：

```cpp
score >= 60 && score < 90
```

它表示 `score` 同时满足下限和上限。

错误示例：

```cpp
60 <= score < 90  // 不要这样写 C++ 区间条件
```

这段代码可能可以编译，但计算方式不是数学中的连续比较，会得到错误含义。

## 5.7 完整例题：合法月份

输入一个整数。如果它在 `1～12` 范围内，输出 `Valid`，否则输出 `Invalid`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int month;
    scanf("%d", &month);

    if (month >= 1 && month <= 12) {
        printf("Valid\n");
    } else {
        printf("Invalid\n");
    }

    return 0;
}
```

建议测试 `0、1、12、13`，它们分别位于下边界外、下边界、上边界、上边界外。

## 第 5 章练习

### 基础练习 1：区间

写出“`x` 在 `10～20` 之间，包含 10 和 20”的条件。

### 基础练习 2：优惠

输入年龄和学生标记 `student`。`student` 为 `1` 表示学生，为 `0` 表示不是学生。年龄不超过 12 或者是学生时输出 `Discount`，否则输出 `Regular`。

### 提高练习 3：闰年规则的第一步

本题只练组合条件，不要求完整闰年规则。输入年份，如果它能被 4 整除并且不能被 100 整除，输出 `Special`，否则输出 `Normal`。

### 判断练习 4

已知 `score = 75`、`attendance = 70`、`special = 1`，判断下面条件是否成立：

```cpp
(score >= 60 && attendance >= 80) || special == 1
```
