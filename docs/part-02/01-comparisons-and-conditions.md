# 第 1 章 条件与比较运算

## 1.1 什么是条件

条件是一句可以判断“成立”或“不成立”的话。例如：

- `age >= 13`：年龄是否至少为 13；
- `score < 60`：成绩是否低于 60；
- `n % 2 == 0`：`n` 除以 2 的余数是否等于 0。

C++ 会把成立的条件看作 `true`，把不成立的条件看作 `false`。

- `true`：读作“真”，表示成立；
- `false`：读作“假”，表示不成立。

第一部分第 2 章学过的 `bool` 类型正好可以保存这两种结果。

## 1.2 六个比较运算符

| C++ 写法 | 含义 | 例子 | 例子何时成立 |
|---|---|---|---|
| `>` | 大于 | `age > 12` | `age` 大于 12 |
| `<` | 小于 | `temperature < 0` | 温度低于 0 |
| `>=` | 大于或等于 | `score >= 60` | 分数至少为 60 |
| `<=` | 小于或等于 | `height <= 150` | 身高不超过 150 |
| `==` | 等于 | `n % 2 == 0` | 余数等于 0 |
| `!=` | 不等于 | `answer != 10` | 答案不是 10 |

注意：`>=`、`<=`、`==`、`!=` 都由两个符号组成，中间不能加空格，也不能交换顺序。

## 1.3 最容易写错：`=` 和 `==`

```cpp
x = 5;
```

一个等号 `=` 表示**赋值**：把右边的 `5` 放进变量 `x`。

```cpp
x == 5
```

两个等号 `==` 表示**比较**：询问“`x` 是否等于 5”。它不会修改 `x`。

可以这样记：

```text
=   把值放进去
==  问两边一样吗
```

## 1.4 比较结果也可以保存

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    scanf("%d", &score);

    bool passed = score >= 60;
    printf("%d\n", passed);
    return 0;
}
```

当输入 `75` 时，条件成立，输出 `1`；输入 `40` 时，条件不成立，输出 `0`。

这里的 `1` 和 `0` 是 `printf("%d", ...)` 输出 `bool` 时看到的数字。现阶段理解为：

- `1`：成立；
- `0`：不成立。

下一章会让程序在条件成立时真正执行一项任务，而不只是输出 `1` 或 `0`。

## 1.5 把中文关键词翻译成条件

| 题目中的说法 | 条件 |
|---|---|
| 至少 60 分 | `score >= 60` |
| 超过 60 分 | `score > 60` |
| 最多 100 个 | `count <= 100` |
| 少于 100 个 | `count < 100` |
| 正好是 10 | `x == 10` |
| 不是 10 | `x != 10` |

“至少 60”和“超过 60”不同。正好 `60` 时：

- `score >= 60` 成立；
- `score > 60` 不成立。

正好卡在规则变化位置的数，叫作**边界值**。后面会专门学习怎样测试边界。

## 1.6 奇偶条件

如果 `n` 是整数：

```cpp
n % 2 == 0
```

表示 `n` 除以 2 的余数等于 0，也就是偶数。

```cpp
n % 2 != 0
```

表示余数不等于 0，也就是奇数。这样写对负整数也适用。

## 第 1 章练习

### 基础练习 1：条件翻译

把下面的话写成 C++ 条件：

1. `age` 至少为 12；
2. `score` 低于 60；
3. `number` 等于 100；
4. `n` 是偶数；
5. `remainder` 不等于 0。

### 基础练习 2：判断结果

已知 `int x = 8;`，判断下面条件是 `true` 还是 `false`：

1. `x > 5`
2. `x <= 8`
3. `x == 7`
4. `x != 7`
5. `x % 2 == 0`

### 提高练习 3：能否进入

输入一个整数年龄，输出条件 `age >= 12` 的结果。成立输出 `1`，否则输出 `0`。
