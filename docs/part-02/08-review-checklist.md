# 第二部分复习清单

## 语法卡片

下面用于回忆，不是一段可以整体复制运行的程序：

```cpp
a > b;
a < b;
a >= b;
a <= b;
a == b;
a != b;

if (condition) {
    statement;
}

if (condition) {
    statement1;
} else {
    statement2;
}

if (condition1) {
    statement1;
} else if (condition2) {
    statement2;
} else {
    statement3;
}

condition1 && condition2;
condition1 || condition2;
!condition;
```

## 我应该能回答的问题

1. `true` 和 `false` 分别表示什么？
2. `=` 和 `==` 有什么区别？
3. “至少 60”和“超过 60”分别怎样写？
4. 单分支 `if` 在条件不成立时会怎样？
5. 双分支一次会执行几块代码？
6. 多分支按照什么顺序检查条件？
7. 为什么成绩分档通常从最高标准开始判断？
8. 多个独立的 `if` 与一条 `if...else if...else` 链有什么不同？
9. `&&`、`||`、`!` 分别表示什么？
10. 怎样写“`x` 在 `1～10` 范围内，包含两端”？
11. 为什么不能把 C++ 区间条件写成 `1 <= x <= 10`？
12. `month == 1 || month == 2` 为什么不能省略第二个 `month ==`？
13. 什么是嵌套？什么时候多分支比嵌套更清楚？
14. 什么是边界值？
15. 条件 `score >= 60` 应重点测试哪三个连续整数？
16. 题目已经保证输入合法时，是否必须再次检查范围？

## 写题前检查

- [ ] 我列出了所有互斥情况。
- [ ] 我圈出了“至少”“不超过”“并且”“或者”等关键词。
- [ ] 我没有把 `==` 错写成 `=`。
- [ ] 我根据题意选择了单分支、双分支或多分支。
- [ ] 我的多分支顺序不会让宽松条件挡住严格条件。
- [ ] 混合使用 `&&` 和 `||` 时，我加了括号。
- [ ] 我的花括号成对，缩进能看出层次。
- [ ] 我测试了每个分支和每个边界。
