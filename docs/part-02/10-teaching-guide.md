# 给家长或老师的使用建议

选择结构是孩子第一次遇到“同一段程序可能走不同路线”。这一部分的重点不是背模板，而是学会把中文规则翻译成条件，并主动检查有没有漏掉边界。

## 开始前的准备

孩子适合开始本部分时，通常已经能够：

1. 独立写出 `main` 程序的基本框架；
2. 使用 `int` 保存整数；
3. 使用 `scanf` 读入整数、使用 `printf` 输出结果；
4. 完成整数的 `+、-、*、/、%` 运算；
5. 理解 `n % 2` 表示除以 2 的余数。

如果这些内容仍频繁混淆，先回到第一部分做两三个短程序，不必急着开始复杂条件。

## 建议的陪学方式

每道题先不看代码，让孩子用口头语言完成四件事：

1. 输入是什么？
2. 一共有哪几种互不重叠的情况？
3. 每种情况的条件是什么？
4. 每种情况应该输出什么？

孩子说清楚以后，再把关键词翻译成符号。例如：

```text
至少 60 → score >= 60
低于 60 → score < 60
在 1～12 内 → month >= 1 && month <= 12
```

不要一看到错误就给出完整代码。可以依次问：

- 这个条件在输入边界时成立吗？
- 程序会先检查哪一支？
- 这条输出在花括号里面还是外面？
- 能不能找一组数据，让程序走到这个分支？

## 新内容出现顺序

| 章节 | 首次正式学习 | 暂时不扩展 |
|---|---|---|
| 第 1 章 | `true`、`false`、六个比较运算符、`=` 与 `==` | 不讲复杂布尔代数和底层表示 |
| 第 2 章 | 单分支 `if`、圆括号、花括号、缩进 | 不省略花括号 |
| 第 3 章 | `else`、双分支 | 不使用三目运算符 |
| 第 4 章 | `else if`、分支顺序、互斥情况 | 不使用 `switch` |
| 第 5 章 | `&&`、`||`、`!`、区间条件 | 不要求背复杂运算优先级，混用时加括号 |
| 第 6 章 | 一层浅嵌套、合法性判断、边界测试 | 不写多层嵌套，不引入循环和数组 |

教材中的 `\n` 出现在 `printf` 的双引号字符串中，表示输出后换行。它已经在第一部分“格式化输入和输出”中学过，不是新的字符变量，也不需要在这一部分改用 `endl`。

## 最常见的五类错误

### 1. 把 `==` 写成 `=`

不要只让孩子背“两个等号”。请让她说清：`=` 会改变变量，`==` 只询问两边是否相等。

### 2. 忘记边界上的等号

“至少 60”容易误写成 `score > 60`。让孩子固定测试 `59、60、61`，比反复提醒更有效。

### 3. 宽松条件挡住严格条件

成绩分档时，如果先判断 `score >= 60`，95 分也会提前进入“通过”。可以让孩子拿 95 从上到下手工走一遍。

### 4. 把数学连续不等式照搬到 C++

看到 `1 <= x <= 10` 时，引导孩子拆成两个完整问题：`x >= 1` 并且 `x <= 10`。

### 5. 只测普通数据

程序输出过一次正确答案，不代表所有分支都正确。要求每个分支至少有一组测试，每个边界测试“前一个、正好、后一个”。

## 建议课时安排

| 课时 | 内容 | 本课应达到的成果 |
|---:|---|---|
| 1 | 从奇偶问题认识条件；`true` 与 `false` | 能口头判断简单条件是否成立 |
| 2 | 六个比较运算符；`=` 与 `==` | 能把中文规则翻译成条件 |
| 3 | 单分支 `if` 与执行路线 | 能指出哪些语句可能被跳过 |
| 4 | 单分支练习与改错 | 独立完成零、奖励、整除提示 |
| 5 | 双分支 `if...else` | 能解释为什么一次只走一支 |
| 6 | 奇偶、较大值、及格线 | 会测试边界前后数据 |
| 7 | 多分支与正数、零、负数 | 能列出三种互斥情况 |
| 8 | 成绩分档与分支顺序 | 会从高标准向低标准判断 |
| 9 | `&&` 与区间条件 | 能写出包含两端的区间 |
| 10 | `||`、`!` 与组合条件 | 能逐项说出组合条件的真假 |
| 11 | 浅层嵌套 | 能画出最多两层的路线图 |
| 12 | 边界测试与合法性判断 | 能独立设计一组边界数据 |
| 13～14 | 综合项目 | 不看参考代码完成判定器 |
| 15～16 | 订正、变式与闯关 | 能解释代码并独立改规则 |

每课建议 45～60 分钟。若孩子在 30 分钟后明显疲劳，可以停在一个能运行的小程序处，下次继续。

## 怎样判断可以进入循环结构

不要求孩子把所有练习都做得很快。满足下面大部分条件，就可以进入下一部分：

- 不看模板写出完整的 `if...else`；
- 能解释 `=`、`==`、`>=`、`&&`、`||`；
- 面对三档规则，能先列情况再安排顺序；
- 能独立找到至少一个边界，并设计边界两侧的数据；
- 综合项目在提示不超过两次的情况下能够完成；
- 代码出错时愿意根据第一条编译信息或错误样例检查，而不是随机修改。

如果主要问题只是打字慢，可以继续学习；如果条件含义和执行路线仍经常混淆，应先用更短的题目巩固。

## 可做的轻量变式

完成原题后，每次只改一条规则，例如：

- 把及格线从 60 改成 65；
- 把三档成绩改成四档；
- 给合法月份题增加 `Winter`、`Summer`、`Other` 三种结果；
- 把项目的优秀条件改成“分数至少 90 或完成全部 10 题”。

修改前先让孩子指出需要改变的是条件、分支顺序还是输出文字。不要同时加入循环、数组或新语法。
