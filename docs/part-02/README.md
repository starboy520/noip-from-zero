## 完成目标

学完后，孩子应当能够：

- 判断一个比较表达式是成立还是不成立；
- 区分赋值符号 `=` 和相等比较符号 `==`；
- 根据题意选择单分支、双分支或多分支结构；
- 使用 `&&`、`||`、`!` 组合简单条件；
- 画出简单选择结构的执行路线；
- 找到分数线、年龄、时间等问题的边界值并主动测试；
- 不使用循环、数组和自定义函数，独立完成综合项目。

## 学习约定

- 每个例题都要先预测输出，再运行验证。
- 改变条件左右两边的数，观察程序走哪条路。
- 写多分支程序前，先在纸上列出所有情况。
- 暂时不使用 `switch`、三目运算符、循环、数组和自定义函数。
