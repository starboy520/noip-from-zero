# 导读：程序怎样学会“做选择”

第一部分的程序通常从上到下执行，每条语句都会运行。例如，输入两个数、求和、输出结果。

但生活中经常需要先判断，再选择做什么：

- 如果下雨，就带伞；
- 如果成绩达到 60 分，就显示“通过”；
- 如果一个整数除以 2 的余数为 0，就说明它是偶数；
- 如果温度低于 0℃，就提醒注意结冰。

程序也可以根据条件选择不同的执行路线，这叫作**选择结构**，也常叫作**分支结构**或**条件判断**。

## 从已经学过的取余出发

第一部分已经会计算：

```cpp
int remainder = n % 2;
```

它只能算出余数。学会选择结构以后，程序还可以继续判断：

```text
余数等于 0 → 输出 Even
余数不等于 0 → 输出 Odd
```

这一部分会把这张路线图真正写成 C++ 程序。

## 本部分难在哪里

选择结构不是背一行模板。真正重要的是三件事：

1. **条件写对**：例如“至少 60 分”应写成 `score >= 60`；
2. **情况分全**：不能漏掉正好 60 分；
3. **路线看清**：一次运行到底会执行哪一块代码。

## 每次学习的固定动作

1. 用自己的话说出题目的所有情况；
2. 圈出“至少”“不超过”“并且”“或者”等关键词；
3. 写出条件，不急着写整个程序；
4. 用一个成立的数据和一个不成立的数据手工验证；
5. 写完程序后测试边界值。

## 暂时不会出现的内容

这一部分只学习选择结构。为了让难度平缓，暂时不引入：

- 循环；
- 数组；
- 自定义函数；
- `switch`；
- `条件 ? 结果1 : 结果2` 这种三目运算符。
