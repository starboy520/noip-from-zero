# 第 3 章 双分支 `if...else`

## 3.1 两种情况必须选择一种

有些题目要求无论条件是否成立，都要输出一个结果：

- 是偶数，输出 `Even`；否则输出 `Odd`；
- 成绩达到 60，输出 `Pass`；否则输出 `Fail`。

这时使用双分支结构：

```cpp
if (条件) {
    条件成立时执行的语句;
} else {
    条件不成立时执行的语句;
}
```

`else` 是英文“否则”的意思。一次运行只会进入两块代码中的一块，不会两块都执行。

## 3.2 完整例题：判断奇偶

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);

    if (n % 2 == 0) {
        printf("Even\n");
    } else {
        printf("Odd\n");
    }

    return 0;
}
```

执行路线：

```text
n % 2 == 0 成立吗？
  ├─ 成立 → 输出 Even
  └─ 不成立 → 输出 Odd
```

不需要再写一次“奇数条件”。`else` 已经包含了“不满足偶数条件”的所有情况。

## 3.3 完整例题：是否及格

### 题目

输入一个 `0～100` 的整数成绩。成绩至少为 60 时输出 `Pass`，否则输出 `Fail`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    scanf("%d", &score);

    if (score >= 60) {
        printf("Pass\n");
    } else {
        printf("Fail\n");
    }

    return 0;
}
```

最应该测试的数据不是随便两个数，而是：

- `59`：刚好低于分数线；
- `60`：正好等于分数线；
- `61`：刚好高于分数线。

如果把条件误写成 `score > 60`，输入 `60` 就会暴露错误。

## 3.4 判断两个数的大小

输入两个不同的整数，输出较大的数：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    scanf("%d%d", &a, &b);

    if (a > b) {
        printf("%d\n", a);
    } else {
        printf("%d\n", b);
    }

    return 0;
}
```

题目明确保证两个数不同，所以 `a > b` 不成立时，一定是 `b > a`。如果题目没有这个保证，就还要考虑两数相等，这会在下一章学习。

## 3.5 单分支还是双分支

判断方法很简单：

- 题目说“如果……就……”，条件不成立时不用做事：单分支 `if`；
- 题目说“如果……否则……”，两种情况都要处理：双分支 `if...else`。

## 第 3 章练习

### 基础练习 1：正数与非正数

输入一个整数。大于 0 输出 `Positive`，否则输出 `Non-positive`。

### 基础练习 2：门票

输入年龄。年龄不超过 6 岁输出 `Free`，否则输出 `Paid`。

### 提高练习 3：较小值

输入两个不同的整数，输出较小的一个。

### 提高练习 4：能否整除

输入两个整数 `a`、`b`，保证 `b != 0`。如果 `a % b == 0`，输出 `Yes`，否则输出 `No`。

- [ ] 我知道双分支每次只执行其中一块。
- [ ] 我能根据题意选择单分支或双分支。
- [ ] 我会在分数线附近测试“前一个、正好、后一个”。
