# 第 2 章 单分支 `if`

## 2.1 只在条件成立时做一件事

`if` 是英文“如果”的意思。单分支结构表示：**如果条件成立，就执行一块代码；不成立就跳过。**

```cpp
if (条件) {
    条件成立时执行的语句;
}
```

先认识新符号：

- `if`：如果；
- 圆括号 `()`：里面放条件；
- 左花括号 `{`：条件成立时要执行的代码从这里开始；
- 右花括号 `}`：这块代码到这里结束；
- 花括号里面通常向右缩进 4 个空格，让结构更清楚。

## 2.2 第一个 `if` 程序

输入一个整数。如果它是正数，就输出 `Positive`：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);

    if (n > 0) {
        printf("Positive\n");
    }

    printf("End\n");
    return 0;
}
```

输入 `5` 时：

```text
Positive
End
```

输入 `-2` 时：

```text
End
```

第二个输入中，`n > 0` 不成立，所以程序跳过花括号中的输出；`printf("End\n");` 在 `if` 外面，无论条件是否成立都会执行。

## 2.3 用路线图跟踪程序

```text
读入 n
  ↓
n > 0 成立吗？
  ├─ 成立 → 输出 Positive
  └─ 不成立 → 跳过
  ↓
输出 End
```

读代码时，不要把 `if` 块里的语句当作“一定执行”。先判断条件，再决定是否进入花括号。

## 2.4 完整例题：偶数提示

### 题目

输入一个整数。如果它是偶数，输出 `Even`。如果不是偶数，什么也不额外输出。

### 思考

偶数条件是：

```cpp
n % 2 == 0
```

### 程序

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);

    if (n % 2 == 0) {
        printf("Even\n");
    }

    return 0;
}
```

## 2.5 花括号为什么重要

即使 `if` 里面暂时只有一条语句，也建议初学时始终写花括号：

```cpp
if (score >= 60) {
    printf("Pass\n");
}
```

这样以后增加语句时不容易误解执行范围。缩进帮助人阅读，花括号才真正决定代码块的范围。

## 2.6 常见错误

### 错误 1：把比较写成赋值

```cpp
if (n = 0) {  // 错误意图：本来想判断 n 是否等于 0
    printf("Zero\n");
}
```

判断相等应写成：

```cpp
if (n == 0) {
    printf("Zero\n");
}
```

### 错误 2：条件后面多写分号

```cpp
if (score >= 60); {  // 不要这样写
    printf("Pass\n");
}
```

`if (条件)` 后面不要写分号。分号会提前结束受条件控制的语句，使花括号中的代码不再按预期工作。

### 错误 3：误以为后面的语句也受控制

```cpp
if (score >= 60) {
    printf("Pass\n");
}
printf("Finished\n");
```

这里只有第一条输出在 `if` 中，`Finished` 总会输出。
